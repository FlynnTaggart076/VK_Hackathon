# Change request: DeepSeek-диспетчер в помощнике

Решение владельца 2026-09-30. Дополняет [change-request-dialog-house-lookup.md](change-request-dialog-house-lookup.md).

## Поведение

- **Сообщения без модели.** Нажатие кнопки, текст, совпадающий с подписью известной кнопки, команды и распознанный ответ на уточнение (город, услуга, адрес, выбор дома) обрабатываются кодом.
- **Остальной свободный текст** уходит в DeepSeek: один вызов `deepseek.route()` на сообщение. Модель возвращает одно из четырёх решений:
  - `run` — функция из каталога и её параметры;
  - `clarify` — вопрос и 2–5 кнопок, каждая привязана к функции из каталога;
  - `answer` — короткий ответ о самом приложении по `knowledge/assistant/context.md`, при необходимости с кнопками;
  - `offtopic` — возврат к теме ЖКХ.
- **Проверка решения сервером** (`app/services/capabilities.py`):
  - функция и параметры должны быть из `knowledge/assistant/capabilities.yaml`;
  - подпись кнопки не длиннее 40 символов;
  - в ответе нет ссылок и телефонов, а числа — только те, что есть в контексте проекта или в вопросе.

  Некорректное решение отбрасывается, и отвечает прежний путь на правилах. Так же он срабатывает при недоступности DeepSeek: таймаут, ошибка или отключённая нейросеть.
- **Выполнение функций.** Функции исполняет существующий код: поиск дома, карточки тем с источниками, сравнение квитанций, переходы в мини-приложении. На вопросы о ЖКХ (тарифы, законы, суммы) модель по своим знаниям не отвечает.
- **Память диалога.** В `dialog_states.state.history` хранятся последние 3 обмена репликами, с уже вырезанными адресом, телефонами и номерами. Они передаются модели, поэтому реплики вроде «а горячей?» или «да, давай» продолжают разговор.
- **Нейросеть включена по умолчанию.** Отключить можно кнопкой «Без нейросети» или командой `/llm_off` (сохраняется в `profiles.chat_llm_opt_out_at`, миграция `e6_llm_opt_out`), включить снова — `/llm_on`. Уведомление об обработке данных поднято до версии 3.0: перед следующей загрузкой квитанции пользователь подтверждает его заново.
- **Переформулировка ответов отключена.** `classify()` и `phrase()` в диалоге больше не вызываются; они остались только в прежнем методе `/assistant/answers`.

## Проверка

`scripts/eval_assistant_router.py` прогоняет 40 случаев из `fixtures/assistant/router_cases.json` через живой DeepSeek:
- функции;
- уточнения;
- вопросы о приложении;
- посторонние темы и попытки подменить инструкции;
- продолжения диалога.

Результат 2026-09-30 на `deepseek-flash`: 40 из 40, медиана 1,4 с, максимум 2,1 с. Автотесты (`tests/test_e6_router.py` и обновлённые тесты диалога) используют замоканный DeepSeek.
